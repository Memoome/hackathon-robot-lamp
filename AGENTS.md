# Project entry point

Read README.md, docs/PROJECT-STATE.md, and apps/LJWB03-Lamp-Demo/VISUAL-STUDIO.md. Main application is apps/LJWB03-Lamp-Demo/visual_control.py. Generated gestures are in expressive_routines.py. Preserve calibration and reference profiles unless the user asks to change them.

This is a public portable source export. Do not assume the original user's C: drive layout, board serial, credentials or controller processes. Select the intended hardware by VID/PID and optional LJWB03_SERIAL. Do not reset/flash or move the robot merely to inspect the project. Original desktop context/transcripts and private device backups are deliberately omitted.

Preview is geometry-based, not feedback. Continuous base has no angle tracking. Network foundation is not a working LJYD voice/action bridge. Pose benchmark is separate and not live posture recognition. Keep those distinctions in user reports.
